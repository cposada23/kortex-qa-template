# Playbook — Test case peer review

**Status:** stub. Fill out once the peer review subtask has run
on 5+ stories and the team's review conventions are known.

## Planned content

- Review checklist: clarity, coverage, redundancy, automation
  feasibility, schema compliance
- How to deliver feedback (Jira comment vs Teams DM, level of
  detail per finding)
- When to approve vs request changes vs reject
- Calibration with the team's other reviewers — what do they
  catch that you miss, and vice versa
- Common test case anti-patterns

## How to fill this stub

1. Save the next 5 reviews you do in `reviews/`.
2. Look for patterns in what you flag.
3. Promote those patterns here.
4. The truly generic ones become `knowledge/patterns/<slug>.md`.
